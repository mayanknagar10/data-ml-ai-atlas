# Data, ML & AI Atlas v2.5.0 — Learning UX Edition

This release changes the Atlas from a content-heavy catalog into a more intentional learning product without changing the 394 verified lesson corpus.

## Primary UX changes

- **Continue learning:** the home page remembers the last opened lesson and surfaces a small set of relevant incomplete lessons.
- **Global command search:** `Cmd/Ctrl + K` (or `/`) searches all modules and lessons; arrow keys and Enter work without leaving the keyboard.
- **Role-aware curriculum focus:** selecting a role narrows the home curriculum to modules that contain relevant lessons. Opening a module directly always exposes its complete lesson set.
- **Clearer progress:** the home dashboard and module pages show completion context without turning every surface into a progress widget.
- **Reader focus:** lessons now show reading progress, lesson position within the module, a compact table of contents, previous/next navigation, and non-disruptive completion controls.
- **Scannable collections:** Roadmap is collapsed by module; Labs, Visual Atlas, and Resources have dedicated filters; Study Paths preview the most useful lessons before expanding.
- **Accessibility:** skip navigation, visible keyboard focus, labeled completion controls, semantic buttons/links, and reduced-motion handling are integrated into the main shell.

## What did not change

- 45 modules
- 394 verified full chapters
- 394 runnable labs
- 788 research-grounded figures
- split-loaded lesson architecture
- publication-style math and source attribution

## Design intent

The interface now gives the learner four recurring actions: **find**, **continue**, **study**, and **practice**. Secondary catalogs remain available, but the landing page no longer treats all 394 lessons as equally urgent at once.
