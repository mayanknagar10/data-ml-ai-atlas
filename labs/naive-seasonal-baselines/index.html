Naive, Seasonal-Naive & Drift Baselines

Build naive and seasonal-naive forecasts before complex models.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
y=np.array([10,12,11,13,15,16,14,11,13,12,14,16,17,15],float)
h=7
last=np.repeat(y[-1],h)
seasonal=y[-7:]
print('last',last,'seasonal',seasonal)

2 · Use it

The same idea through a common library or practical API.

def mae(a,b): return np.mean(np.abs(a-b))
actual=np.array([12,14,13,15,17,18,16],float)
print('MAE last',mae(actual,last),'seasonal',mae(actual,seasonal))

Ship a seasonal-naive fallback beside every forecasting service; if the complex model cannot beat it by segment/horizon, revisit the model or data.
