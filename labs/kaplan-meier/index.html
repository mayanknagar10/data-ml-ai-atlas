Kaplan–Meier Estimator & Log-rank Test

Fit and inspect a Kaplan–Meier survival curve.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
t=np.array([1,2,2,3,5],float); e=np.array([1,1,0,1,0])
s=1.0
for time in sorted(set(t[e==1])):
    at_risk=(t>=time).sum(); events=((t==time)&(e==1)).sum(); s*=1-events/at_risk
    print(time,s)

2 · Use it

The same idea through a common library or practical API.

from lifelines import KaplanMeierFitter
km=KaplanMeierFitter().fit(t,event_observed=e)
print(km.survival_function_)

Production survival dashboards should define event/censoring rules, cohort entry, timezone/window semantics and delayed labels explicitly.
