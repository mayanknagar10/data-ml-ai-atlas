t-SNE & UMAP for Visualization

Create PCA and t-SNE maps, quantify trustworthiness, and verify fixed-seed reproducibility and finite coordinates.

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
from sklearn.datasets import make_blobs
from sklearn.manifold import TSNE,trustworthiness
from sklearn.preprocessing import StandardScaler
X,_=make_blobs(n_samples=180,centers=4,n_features=8,cluster_std=1.2,random_state=2); X=StandardScaler().fit_transform(X)
tsne=TSNE(n_components=2,perplexity=20,init='pca',learning_rate='auto',random_state=7,max_iter=500).fit_transform(X)
tw_tsne=float(trustworthiness(X,tsne,n_neighbors=10))

2 · Use it

The same idea through a common library or practical API.

from sklearn.decomposition import PCA
pca=PCA(n_components=2,random_state=7).fit_transform(X); tw_pca=float(trustworthiness(X,pca,n_neighbors=10))
tsne_again=TSNE(n_components=2,perplexity=20,init='pca',learning_rate='auto',random_state=7,max_iter=500).fit_transform(X)

3 · Ship it

Freeze reference data, preprocessing, seed and layout parameters; store neighbor-quality metrics; repeat sensitivity runs; never infer global distance or density without original-space evidence; retain a PCA fallback.

4 · Verify it

Assertions and sanity checks that catch conceptual or implementation mistakes.

assert tsne.shape==(len(X),2) and pca.shape==(len(X),2)
assert np.isfinite(tsne).all() and np.isfinite(pca).all()
assert np.allclose(tsne,tsne_again)
assert .5<=tw_tsne<=1 and .5<=tw_pca<=1
assert tw_tsne>0.9
assert not np.allclose(tsne,pca)
