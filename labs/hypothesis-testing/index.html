Hypothesis Testing & p-values

Compute a simple two-sample mean test and connect the statistic to the null hypothesis.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import math
a=[10,11,9,12,10,11]; b=[13,12,14,11,13,14]
def mean(x): return sum(x)/len(x)
def var(x):
    m=mean(x); return sum((v-m)**2 for v in x)/(len(x)-1)
se=math.sqrt(var(a)/len(a)+var(b)/len(b))
t=(mean(b)-mean(a))/se
print('difference',mean(b)-mean(a),'t statistic',t)

2 · Use it

The same idea through a common library or practical API.

from scipy.stats import ttest_ind
print(ttest_ind(b,a,equal_var=False))
