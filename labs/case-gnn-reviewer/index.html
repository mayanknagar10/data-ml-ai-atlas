Case Study: Graph-based Matching & Recommendation

Score a toy reviewer–paper graph and solve a conflict- and capacity-constrained assignment with verified invariants.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
from scipy.optimize import linear_sum_assignment
# Three papers each need one reviewer; two slots model capacity for reviewer 0.
content=np.array([[.9,.6,.3],[.8,.4,.7],[.2,.85,.65]])
graph=np.array([[.1,.7,.2],[.5,.2,.8],[.1,.6,.4]])
scores=.7*content+.3*graph
conflicts=np.array([[False,True,False],[False,False,True],[False,False,False]])
slots=[0,0,1,2]; expanded=scores[:,slots].copy()
for p in range(3):
    for j,r in enumerate(slots):
        if conflicts[p,r]: expanded[p,j]=-1e6
rows,cols=linear_sum_assignment(-expanded); assignment=[(int(p),slots[int(c)]) for p,c in zip(rows,cols)]

2 · Use it

The same idea through a common library or practical API.

capacities={0:2,1:1,2:1}; loads={r:sum(rr==r for _,rr in assignment) for r in capacities}; utility=sum(scores[p,r] for p,r in assignment)

3 · Ship it

Version graph time and constraints, preserve content cold-start fallback, evaluate feasible assignment and exposure, log overrides safely, and roll back scoring independently of hard policy.

4 · Verify it

Assertions and sanity checks that catch conceptual or implementation mistakes.

assert len(assignment)==3 and {p for p,_ in assignment}=={0,1,2}
assert all(not conflicts[p,r] for p,r in assignment)
assert all(loads[r]<=capacities[r] for r in capacities)
assert utility>1.5
# Content-only remains available for nodes without graph history.
cold_score=content[0]; assert cold_score.argmax()==0
assert np.isfinite(scores).all()
