Regularization as Capacity Control

Implement ridge regression, compare scikit-learn, and verify monotone coefficient norm, training risk and effective degrees of freedom along a regularization path.

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
rng=np.random.default_rng(19); X=rng.normal(size=(45,20)); true=np.r_[2,-1.5,.8,np.zeros(17)]; y=X@true+rng.normal(scale=1.5,size=45)
# Center to keep the intercept outside the penalty.
Xc=X-X.mean(0); yc=y-y.mean()
def ridge(X,y,lam): return np.linalg.solve(X.T@X+lam*np.eye(X.shape[1]),X.T@y)
def mse(y,p): return float(np.mean((y-p)**2))
def effective_df(X,lam):
    s=np.linalg.svd(X,compute_uv=False); return float(np.sum(s*s/(s*s+lam)))
lambdas=np.array([.01,.1,1,10,100]); coefs=[ridge(Xc,yc,l) for l in lambdas]; norms=np.array([np.linalg.norm(w) for w in coefs]); risks=np.array([mse(yc,Xc@w) for w in coefs]); dfs=np.array([effective_df(Xc,l) for l in lambdas])

2 · Use it

The same idea through a common library or practical API.

from sklearn.linear_model import Ridge
sk=Ridge(alpha=1,fit_intercept=False,solver='cholesky').fit(Xc,yc); ours=ridge(Xc,yc,1)

4 · Verify it

Assertions and sanity checks that catch conceptual or implementation mistakes.

assert np.allclose(sk.coef_,ours)
assert np.all(np.diff(norms)<0)
assert np.all(np.diff(risks)>0)
assert np.all(np.diff(dfs)<0)
assert 0<dfs[-1]<dfs[0]<=Xc.shape[1]
assert np.linalg.norm(coefs[-1])<np.linalg.norm(coefs[0])
# Orthogonal change of feature coordinates preserves ridge predictions and norm.
Q,_=np.linalg.qr(rng.normal(size=(20,20))); rotated=ridge(Xc@Q,yc,1); assert np.allclose(Xc@ours,Xc@Q@rotated)
assert abs(np.linalg.norm(ours)-np.linalg.norm(rotated))<1e-10
