Bagging, Blending & Stacking

Construct leakage-free out-of-fold regression meta-features, fit a stack and verify fold coverage and baseline improvement.

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
from sklearn.model_selection import KFold
from sklearn.linear_model import LinearRegression
from sklearn.tree import DecisionTreeRegressor
rng=np.random.default_rng(4); X=rng.uniform(-2,2,(120,2)); y=1.5*X[:,0]+X[:,1]**2+rng.normal(0,.15,120)
kf=KFold(5,shuffle=True,random_state=5); oof=np.zeros((len(X),2)); seen=np.zeros(len(X),int)
for train,val in kf.split(X):
    models=[LinearRegression(),DecisionTreeRegressor(max_depth=3,random_state=0)]
    for j,m in enumerate(models): oof[val,j]=m.fit(X[train],y[train]).predict(X[val])
    seen[val]+=1
meta=LinearRegression().fit(oof,y)
base_full=[LinearRegression().fit(X,y),DecisionTreeRegressor(max_depth=3,random_state=0).fit(X,y)]
stack_train=meta.predict(oof)

2 · Use it

The same idea through a common library or practical API.

from sklearn.ensemble import StackingRegressor
stack=StackingRegressor(estimators=[('linear',LinearRegression()),('tree',DecisionTreeRegressor(max_depth=3,random_state=0))],final_estimator=LinearRegression(),cv=KFold(5,shuffle=True,random_state=5)).fit(X,y)
sk_pred=stack.predict(X)

4 · Verify it

Assertions and sanity checks that catch conceptual or implementation mistakes.

assert np.array_equal(seen,np.ones(len(X),int))
assert np.isfinite(oof).all()
assert oof.shape==(len(X),2)
assert np.mean((y-stack_train)**2)<np.var(y)
assert np.mean((y-sk_pred)**2)<np.var(y)
assert not np.allclose(oof[:,1],base_full[1].predict(X))
