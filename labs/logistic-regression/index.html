Logistic Regression

Build binary logistic regression and verify probabilities/decision boundary.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
rng=np.random.default_rng(1)
X=rng.normal(size=(300,2)); y=(X[:,0]+.7*X[:,1]>0).astype(float)
Xb=np.c_[np.ones(len(X)),X]; w=np.zeros(3)
def sigmoid(z): return 1/(1+np.exp(-z))
for _ in range(2000):
    p=sigmoid(Xb@w)
    w-=0.1*(Xb.T@(p-y)/len(y))
print('accuracy',((sigmoid(Xb@w)>=.5)==y).mean())

2 · Use it

The same idea through a common library or practical API.

from sklearn.linear_model import LogisticRegression
m=LogisticRegression().fit(X,y)
print(m.score(X,y),m.predict_proba(X[:3]))

3 · Ship it

It is often a superb baseline because it trains fast, is easy to calibrate/interpret and exposes whether more complex models are truly necessary.

4 · Verify it

Assertions and sanity checks that catch conceptual or implementation mistakes.

p=sigmoid(Xb@w)
assert np.all((0<=p)&(p<=1))
assert ((p>=.5)==y).mean()>.9
