Embedding Search & Vector Databases

Build cosine-similarity retrieval over a tiny vector index and return top-k items.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
docs=np.array([[1.,0.],[0.,1.],[.8,.2],[-1.,0.]])
q=np.array([1.,.1])
def norm(x): return x/np.linalg.norm(x,axis=-1,keepdims=True)
scores=norm(docs)@norm(q)
rank=np.argsort(-scores)
print(rank,scores[rank])

The same idea through a common library or practical API.

print('retrieved ids',rank[:top_k].tolist())
