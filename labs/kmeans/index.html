K-means Clustering

Implement K-means assignment/update steps and compare with sklearn.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
rng=np.random.default_rng(0)
X=np.r_[rng.normal([-2,0],.4,(80,2)),rng.normal([2,0],.4,(80,2))]
centers=X[[0,-1]].copy()
for _ in range(20):
    d=((X[:,None,:]-centers[None,:,:])**2).sum(2)
    labels=d.argmin(1)
    centers=np.array([X[labels==k].mean(0) for k in range(2)])
print(centers)

2 · Use it

The same idea through a common library or practical API.

from sklearn.cluster import KMeans
m=KMeans(n_clusters=2,n_init='auto',random_state=0).fit(X)
print(m.cluster_centers_)
