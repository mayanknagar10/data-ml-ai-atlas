Distributions, Skewness & Outliers

Compute classical and robust distribution summaries, flag—not delete—unusual values, and verify translation/scale behavior against NumPy.

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import statistics

def quantile(xs,p):
    ys=sorted(xs); pos=(len(ys)-1)*p; lo=int(pos); hi=min(lo+1,len(ys)-1); frac=pos-lo
    return ys[lo]*(1-frac)+ys[hi]*frac
def robust_summary(xs):
    med=statistics.median(xs); q1=quantile(xs,0.25); q3=quantile(xs,0.75)
    mad=statistics.median([abs(x-med) for x in xs]); iqr=q3-q1
    flags=[x for x in xs if x<q1-1.5*iqr or x>q3+1.5*iqr]
    return {'mean':statistics.mean(xs),'median':med,'q1':q1,'q3':q3,'iqr':iqr,'mad':mad,'flags':flags}

x=[5,7,8,9,10,11,12,13,14,15,80]
report=robust_summary(x)

2 · Use it

The same idea through a common library or practical API.

import numpy as np
a=np.asarray(x,float)
numpy_median=float(np.median(a))
numpy_q=np.quantile(a,[0.25,0.75])

3 · Ship it

Keep raw and corrected values, treat flags as investigation queues, version support/unit/capping rules, monitor tails by source/time, and sensitivity-test model and decision impact before changing records.

4 · Verify it

Assertions and sanity checks that catch conceptual or implementation mistakes.

assert report['median']==numpy_median
assert np.allclose([report['q1'],report['q3']],numpy_q)
assert report['flags']==[80]
shifted=robust_summary([v+100 for v in x])
assert shifted['median']==report['median']+100
scaled=robust_summary([v*3 for v in x])
assert scaled['iqr']==report['iqr']*3
assert 80 in x
