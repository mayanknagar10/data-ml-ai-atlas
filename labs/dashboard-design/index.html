1 · Build it

Minimal implementation with as little framework abstraction as practical.

from dataclasses import dataclass

@dataclass
class Metric:
    value: float
    lower: float
    upper: float
    sample_size: int
    freshness_minutes: int
    complete: bool

def status(metric,minimum,freshness_slo,min_n):
    if not metric.complete: return 'unknown: incomplete'
    if metric.freshness_minutes>freshness_slo: return 'unknown: stale'
    if metric.sample_size<min_n: return 'unknown: low support'
    if metric.upper<minimum: return 'harm'
    if metric.lower>=minimum: return 'healthy'
    return 'uncertain'

good=Metric(0.94,0.93,0.95,5000,10,True)
stale=Metric(0.99,0.98,1.0,5000,180,True)

2 · Use it

The same idea through a common library or practical API.

import pandas as pd
frame=pd.DataFrame([good.__dict__,stale.__dict__])
frame['state']=[status(m,0.90,60,1000) for m in (good,stale)]

Centralize metric and status contracts, gate on data integrity/freshness/support, test filters/security/accessibility/performance, attach owners and runbooks, and fail visibly rather than preserving reassuring stale values.
