Lists, Tuples, Sets & Dictionaries

Compare list, deque, set, and dictionary semantics with assertions for ordering, uniqueness, hashing, and queue behavior.

1 · Build it

Minimal implementation with as little framework abstraction as practical.

from collections import deque
seq=["a","b","a"]
unique=set(seq)
index={value:i for i,value in enumerate(seq)}
queue=deque(seq)
left=queue.popleft(); queue.append("c")

2 · Use it

The same idea through a common library or practical API.

counts={}
for value in seq: counts[value]=counts.get(value,0)+1
ordered_unique=list(dict.fromkeys(seq))

4 · Verify it

Assertions and sanity checks that catch conceptual or implementation mistakes.

assert unique=={"a","b"}
assert index=={"a":2,"b":1}
