Heterogeneous Treatment Effects & Uplift Modeling

Fit a T-learner on randomized heterogeneous effects and verify held-out CATE accuracy, ranking and calibration against known simulation truth.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
from sklearn.ensemble import ExtraTreesRegressor
from sklearn.model_selection import train_test_split
rng=np.random.default_rng(88); n=14000; X=rng.normal(size=(n,3)); tau=1+1.2*X[:,0]; a=rng.binomial(1,.5,size=n); mu=2*X[:,0]+X[:,1]**2; y=mu+a*tau+rng.normal(scale=.5,size=n)
train,test=train_test_split(np.arange(n),test_size=.35,random_state=4); params=dict(n_estimators=240,min_samples_leaf=40,max_features=1.0,random_state=5,n_jobs=-1); m0=ExtraTreesRegressor(**params).fit(X[train][a[train]==0],y[train][a[train]==0]); m1=ExtraTreesRegressor(**params).fit(X[train][a[train]==1],y[train][a[train]==1]); cate=m1.predict(X[test])-m0.predict(X[test]); truth=tau[test]

2 · Use it

The same idea through a common library or practical API.

rmse=np.sqrt(np.mean((cate-truth)**2)); correlation=np.corrcoef(cate,truth)[0,1]; cuts=np.quantile(cate,[0,.25,.5,.75,1]); groups=np.clip(np.digitize(cate,cuts[1:-1]),0,3); calibration=[(cate[groups==g].mean(),truth[groups==g].mean()) for g in range(4)]

3 · Ship it

Persist cross-fitted effect predictions and calibration groups, gate policy on overlap and held-out value, preserve exploration, and communicate CATE as a conditional average with uncertainty.

4 · Verify it

Assertions and sanity checks that catch conceptual or implementation mistakes.

assert rmse<.35
assert correlation>.95
assert all(abs(pred-actual)<.2 for pred,actual in calibration)
assert calibration[-1][1]>calibration[0][1]+2
assert abs(cate.mean()-truth.mean())<.08
assert len(cate)==len(test)
