Difference-in-Differences

Compute a simple 2x2 difference-in-differences estimate.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

treated_pre=100; treated_post=130
control_pre=90; control_post=100
did=(treated_post-treated_pre)-(control_post-control_pre)
print('DiD',did)

2 · Use it

The same idea through a common library or practical API.

import pandas as pd, statsmodels.formula.api as smf
df=pd.DataFrame({'y':[100,130,90,100],'treated':[1,1,0,0],'post':[0,1,0,1]})
fit=smf.ols('y ~ treated + post + treated:post',data=df).fit()
print(fit.params['treated:post'])

3 · Ship it

A real DiD study needs many units/time periods, pre-trend diagnostics, explicit treatment timing, robust/clustered uncertainty and sensitivity to composition changes.

4 · Verify it

Assertions and sanity checks that catch conceptual or implementation mistakes.

assert abs(did-20)<1e-9
