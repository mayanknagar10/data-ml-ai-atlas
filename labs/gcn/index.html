Graph Convolutional Networks (GCN)

Implement one normalized GCN propagation step with NumPy.

← Full lessonCombined Python fileREADME

1 · Build it

Minimal implementation with as little framework abstraction as practical.

import numpy as np
A=np.array([[0,1,1],[1,0,0],[1,0,0]],float)
X=np.array([[1.,0.],[0.,1.],[1.,1.]])
Ahat=A+np.eye(3); deg=Ahat.sum(1); D=np.diag(1/np.sqrt(deg)); S=D@Ahat@D
W=np.array([[1.,-.5],[.5,1.]])
H=np.maximum(0,S@X@W)
print(H)

2 · Use it

The same idea through a common library or practical API.

print('row norms',np.linalg.norm(H,axis=1))

3 · Ship it

For large graphs use sparse tensors/sampling, version graph snapshots/features and monitor degree/cold-start shifts; full adjacency multiplication will not scale.
